# Student Performance Visualizations

## Overview
This folder contains charts created for the Student Performance Analysis project using Python.

## Visualizations

### 1. Attendance vs Grade
Visualizes the relationship between student attendance and grades.

### 2. Correlation Heatmap
Shows the correlations between numerical variables in the dataset.

### 3. Gender Distribution
Displays the distribution of students by gender.

### 4. Grade Distribution
Shows how student grades are distributed.

### 5. Study Hours vs Grade
Visualizes the relationship between weekly study hours and grades.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Purpose
These visualizations help explore patterns and relationships in student performance data.
