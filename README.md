# Student Performance Analysis

## 1. Project Overview
This project analyzes student performance data using Python and data visualization techniques.

## 2. Objectives
- Explore the student dataset.
- Identify missing values and duplicate records.
- Analyze student grade distributions.
- Explore relationships between attendance, study hours, and grades.
- Visualize student performance patterns.

## 3. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## 4. Dataset
The project uses an original uncleaned Excel dataset and a cleaned Excel dataset.

## 5. Data Analysis
- Data exploration
- Missing-value analysis
- Duplicate detection
- Grade distribution
- Attendance analysis
- Study-hour analysis
- Correlation heatmap

## 6. Project Structure
- dataset/ — Excel datasets
- notebook/ — Python notebook
- visualizations/ — Graphs and charts
- dashboard/ — Optional dashboard
- report/ — Documentation

## 7. How to Run
1. Download the notebook.
2. Open it in Google Colab.
3. Upload the required Excel files.
4. Run the code cells in order.

The findings and conclusions will be added after completing the analysis.
